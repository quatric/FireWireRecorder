# Icon

`FireWire_Logo.svg` is the FireWire logo from Wikimedia Commons
(https://commons.wikimedia.org/wiki/File:FireWire_Logo.svg), where it is marked
public domain; its drop-shadow filters are removed here so it renders sharply
at icon sizes. FireWire and the FireWire logo are trademarks of Apple Inc.;
FireWireRecorder is not affiliated with or endorsed by Apple.

`AppIcon.icns`, `AppIcon-legacy.icns` (scripts/make-legacy-icns.py) and
`windows/app.ico` are made from it.
